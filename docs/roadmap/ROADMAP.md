# Canon AI Trading — Roadmap

**Version:** 1.0 (Analysis + Telegram alerts, manual execution)

## Vision

Build a professional Gold trading intelligence platform that prioritizes signal quality over signal quantity.

## Phase 1 — Foundation

| Sprint | Focus | Status |
|--------|-------|--------|
| Sprint 0 | Project initialization | Complete |
| Sprint 1 | TBD by Product Owner | Pending |

## Phase 2 — Data & Infrastructure

- Data Ingestion Engine (MT5 / XMGlobal)
- Database models and persistence
- API foundation

## Phase 3 — Analysis Engines

Implement one engine per sprint:

- Market Structure
- Smart Money Concepts
- Liquidity
- Trend
- Price Action
- Macroeconomic Events
- News
- Volatility
- Risk

## Phase 4 — Decision & Delivery

- Decision Engine (signals / NO TRADE)
- Notification Engine (Telegram)
- Explainability output format

## Phase 5 — Frontend Dashboard

- Live chart (Lightweight Charts)
- Signal history and reasoning display
- Engine status and configuration UI

## Out of Scope (v1.0)

- Automated trade execution
- Paid third-party APIs
- Multi-symbol support (beyond XAUUSD)

## Roadmap Change Policy

Sprint order and scope require Product Owner approval before implementation.
