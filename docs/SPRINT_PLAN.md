## Sprint Rules

1. One sprint per implementation cycle
2. One engine per sprint
3. One responsibility per engine
4. Stop immediately when sprint deliverables are complete
5. No scope creep into future sprints

## Approval Process

1. Product Owner assigns sprint and engine
2. Implementation Engineer implements within scope
3. Deliverables reviewed against sprint acceptance criteria
4. Next sprint approved explicitly
